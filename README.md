# Robin Singh Portfolio Website

Simple personal portfolio website built with plain HTML, CSS, and JavaScript.

## Project Structure

- `index.html`: main page markup
- `styles.css`: site styling (layout, theme, responsiveness)
- `scripts.js`: filters, dark mode, and mobile menu behavior

## Run Locally

1. Open `index.html` directly in your browser.
2. Optional static server alternative:

```powershell
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Requirements

- A modern browser (Chrome, Edge, Firefox, Safari)
- Optional: Python 3 (only if you want to run a local static server)
